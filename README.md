# Peachy Store

An Expo React Native app written in TypeScript.

## Get started

Install dependencies with `npm install`, then start the app with `npx expo start`.

## Source structure

- `src/components/` — reusable UI components
- `src/screens/` — app screens
- `src/types/` — shared TypeScript types
- `src/data/` — static or fixture data
- `src/utils/` — shared utility functions

The root `App.tsx` is intentionally blank until app features are added.
